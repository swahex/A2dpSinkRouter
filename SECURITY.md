# Security

This project is an early desktop utility. Updates currently target the latest source version; no formal support schedule is promised.

For a potential vulnerability, use GitHub's **Report a vulnerability** under the repository's Security tab if the maintainer has enabled private vulnerability reporting. If it is unavailable, open an issue requesting a private contact without posting exploit details or personal data.

The application stores configuration and logs locally in `%LOCALAPPDATA%\A2dpSinkRouter\`. They can contain device names and endpoint identifiers. Sanitize diagnostic files before sharing.

The program does not request administrator privileges. Pair devices through Windows settings.
